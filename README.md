# Agencia de Viajes

Aplicación web desarrollada en PHP y MySQL para la gestión de servicios turísticos. El sistema permite registrar clientes, vuelos, hoteles y reservas, además de ejecutar consultas sobre la información almacenada en la base de datos.

## Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Estructura del proyecto

```
agencia-viajes/
│
├── clases/
├── css/
├── js/
├── procesos/
├── sql/
├── conexion.php
└── index.php
```

## Funcionalidades

- Registro de clientes.
- Registro de vuelos.
- Registro de hoteles.
- Registro de reservas.
- Consulta simple de tablas.
- Consulta avanzada sobre reservas.
- Validación de formularios mediante JavaScript.

## Trabajo colaborativo

Durante el desarrollo se aplicaron buenas prácticas de GitHub:

- Uso de ramas (Branch).
- Commits pequeños y descriptivos.
- Pull Requests para revisión de cambios.
- Issues para registrar y discutir mejoras.
- Integración mediante Merge hacia la rama principal.
